# DEVVAN 3D Website

Premium 3D website for DEVVAN - Mosquito Repellent Agarbatti brand.

## Features
- Black + Gold + Electric Blue premium theme
- Product showcase: Outer box, inner plastic sleeve, lari hanging strip (12 cards)
- 3D tilt, smoke particles, mobile responsive
- Ready for Vercel deployment

## Deploy to Vercel
1. Push this repo to GitHub
2. Go to vercel.com -> Add New -> Project -> Import this GitHub repo
3. Framework: Other (static)
4. Deploy

Or via CLI:
```
vercel --prod
```

## Structure
- index.html - Full website (single file, no build needed)
